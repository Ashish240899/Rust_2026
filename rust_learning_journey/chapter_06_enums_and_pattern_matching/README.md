# 🦀 Chapter 06: Enums and Pattern Matching

## 🎯 The Vision
This folder contains 10 highly optimized, memory-safe programs designed to master Rust's powerful Enums and Control Flow mechanisms. It entirely eradicates the "Billion Dollar Mistake" (Null References) by strictly enforcing the `Option<T>` enum and exhaustive `match` patterns.

## 🏗️ The Arsenal (Programs)
1. **`01_basic_traffic_light`**: Instantiating custom types with finite variants.
2. **`02_smart_ip_scanner`**: Embedding diverse data types directly into Enum variants.
3. **`03_anonymous_struct_message`**: Utilizing Anonymous Structs for localized, memory-efficient data packing.
4. **`04_banking_enum_method`**: Contextualizing functions on Enums using `impl` blocks.
5. **`05_coin_sorter_match`**: Executing logic via exhaustive `match` control flow.
6. **`06_match_with_state_data`**: Unlocking and binding inner Enum data using pattern matching.
7. **`07_option_enum_math`**: Hardcore implementation of `Option<T>` for Null-free memory safety.
8. **`08_catch_all_dice_game`**: Handling infinite possibilities using the `_` (catch-all) placeholder.
9. **`09_if_let_admin_config`**: Writing concise, sugar-syntax control flows via `if let`.
10. **`10_mega_inventory_system`**: The ultimate CTO-level architecture combining Enums, Options, and match.

> **"Built with the Machine Mindset. Zero Nulls. 100% Pattern Matched."**
